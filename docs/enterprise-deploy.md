# 可选自建部署（Draft）

| 项 | 内容 |
|---|---|
| 状态 | Draft（2026-09-14） |
| 关联 | ADR-002、team-library-schema.md |

## 原则

1. **代码同源**：与默认云端部署同一 monorepo
2. **默认零知识**：密钥在客户端；托管密钥为显式 opt-in
3. **可离线运行**：核心本地能力不依赖公网

## 说明

桌面端与 CLI 默认本地优先；云同步/团队库为可选组件，可部署到自有对象存储与 API。

本文档不绑定具体内部客户端产品；适配能力以各 adapter 的 `capabilities` 为准。
