## 原则

1. **代码同源**：与社区版同一 monorepo，构建时 `HARBOR_EDITION=enterprise`
2. **数据面物理隔离**：独立数据库、对象存储、密钥域；绝不出内网
3. **默认零知识**：个人模式密钥在客户端；企业托管密钥为显式 opt-in
4. **可完全离线**：安装包 + 内网更新源，不依赖 npm/github 直连

## 组件

| 组件 | 社区版 | 企业内网版 |
|---|---|---|
| 桌面客户端 | 公网下载 | 内网制品库 / U 盘分发 |
| 同步 API | 公有云 | 内网 K8s/虚机 |
| 对象存储 | S3 兼容云 | MinIO / Ceph |
| 数据库 | 托管 PG | 内网 PG |
| 身份 | 邮箱/OAuth | LDAP / 企业 SSO（OIDC） |
| 遥测 | 可选 | 默认关闭 |

## 覆盖客户端

- 必选：领慧AI工作台、WorkBuddy（零竞品主场）
- 可选：内网部署的 MiMo、Codex（若合规允许）

## 运维要点

1. **备份**：PG + MinIO 每日快照；客户端本地仍保留原始 jsonl
2. **升级**：客户端静默检查内网 update feed；schema 指纹失败 → 只读降级（R3）
3. **审计**：共享/导出/迁移动作写入 `shared_session_audit`
4. **合规**：密钥托管模式需员工知情；默认关闭

## 验收（M3）

- [ ] 双设备同步一致性
- [ ] 内网离线安装包可重复部署
- [ ] 数据不出内网的网络策略证明（无公网出口依赖）
